# CHANGELOG: NoKing Protocol `v0.3-draft` → `v0.4-draft`

Все изменения в [`protocol/specs/exchange-spec-v0.4.md`](../../protocol/specs/exchange-spec-v0.4.md) внесены строго по утверждённым решениям **F1–F5** и дополнительным предложениям по закрытию `M-02`, `M-07`, `M-08`, `M-09`.

| Раздел v0.4 | Что изменено | Основание (Решение / Проблема v0.3) |
|---|---|---|
| §2.5, §3.2, §4.2 | Вместо быстрого 50/50 split в Раунде 1 введена трёхуровневая цепочка эскалации (`Category → Parent → GLOBAL`) с **растущей наградой арбитрам** за неудачные попытки; сплит 50/50 с потерей `D_dispute` — только после исчерпания всей цепочки (`esc_level = 2`) и `T_dispute_max`; нераскрывшие/отказавшиеся арбитры исключаются из следующих попыток (`anti-farming`) | **F1** (`M-01`) |
| §2.3, §3.2, §5.1, §8 | `OVERSAMPLE` снижен с `3×` до **`2×`**; введён жёсткий потолок суммы **`V_protocol_max(tier)`**, проверяемый на контракте в `e_create`; добавлен отдельный раздел §8 **«Границы применимости»** | **F2** (`M-04`, `M-05`) |
| §2.5, §3.2, §5.2 | Скрытие промежуточного счёта `(v_A, v_B)` в `e_redraw` до достижения `Q_arb` (`tally_sealed`); добавлено правило предварительного добора по пропускам `commit` до этапа `reveal` и требование пороговой/timelock-криптографии на EVM | **F3** (`M-03`) |
| §2.3, §4.1, §9 | При `REVIEW --e_timeout--> CLOSED` **100% `protocol_fee`** уходит киперу; `A_min = 50 USDC` (вариант `A_min = 250` исключён) | **F4** (`M-10`) |
| §2.1, §3.2, §6.2 | Исключена идея автоматического `1★` при `EXPIRED`; добавлено отдельное объективное измерение **`reliability`** (`deadline_defaults`, взвешенное по объёму `V/V_ref`), учитываемое только при срывах продавца `LOCKED`/`IN_PROGRESS → EXPIRED` и влияющее на `effective_rating` и допуск арбитров | **F5** |
| §2.2, §2.3, §6.2 | Закрыты дополнительные уязвимости v0.3: допуск `unique_counterparties` усилен порогом оборота **`V_arb_min`** (`M-08`); двухфазная отмена в `DRAFT` `e_cancel_request + T_cancel_delay` (`M-09`); запрет создания сделок в категориях с `< OVERSAMPLE·k` арбитров (`M-02`); скользящее окно суммарного оборота пары `T_split_window` против дробления (`M-07`) | Доп. предложения (`M-02`, `M-07`, `M-08`, `M-09`) |
