# X4. Агентные симуляции NoKing v0.4 (`03_simulation`)

## 1. Воспроизведение и окружение

- **Скрипт:** [`sim_noking_v04.py`](sim_noking_v04.py)
- **Инструмент:** Python `3.11.2`, `numpy`, `pandas`, `matplotlib` (`/tmp/noking_venv`).
- **Воспроизводимость:** `20` независимых прогонов (`SEEDS = 100..119`), `95%` ДИ ($1.96 \cdot s / \sqrt{20}$). Сводка: [`summary_v04.json`](summary_v04.json).
- **Принцип условности (Правило 4):** каждый результат, зависящий от гипотез о поведении людей (`herd`, `p_unrev`, `η`, распределение капитала, координация коалиций), явно помечен как **условный** с указанием диапазона параметров, в котором он верен.

```bash
cd verification/v0.4/03_simulation
/tmp/noking_venv/bin/python sim_noking_v04.py
```
