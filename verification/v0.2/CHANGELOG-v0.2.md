# CHANGELOG: NoKing Protocol `v0.1-draft` → `v0.2-draft`

Все изменения в [`protocol/specs/exchange-spec-v0.2.md`](../../protocol/specs/exchange-spec-v0.2.md) выполнены строго по утверждённым решениям **D1–D11** и дополнительным поручениям автора. Открытые пробелы помечены `[OPEN]`.

| Раздел v0.2 | Что изменено | Основание (Решение / Проблема v0.1) |
|---|---|---|
| §2.3, §3.3, §4.1, §4.3 | `seller_deposit` вносится `party_a` при создании `DRAFT` (`e_create`); `e_accept` блокирует `amount` от `party_b`; `e_cancel` в `DRAFT` доступен только `party_a` и возвращает `seller_deposit`; §4.3 согласован с §4.1 | **D1** (`A-01`, `G-02`, `lit_trapped_funds.log`) |
| §2.3, §3.1–3.3, §5.5–5.6 | Добавлено состояние `APPEALABLE`, события `e_appeal` и `e_finalize` (вызывает любой после `T_appeal`), поле `resolve_time`; выплаты при раунде 1 перенесены на `RESOLVED`; раунд 2 сразу переходит в финальный `RESOLVED` | **D2** (`A-02`, `lit_double_payout.log`) |
| §2.5, §3.2–3.3, §4.4, §5.2, §9 | Введён параметр `T_dispute_max` и переход `e_dispute_timeout`: при провале формирования панели или отсутствии вердикта в срок возвращаются `amount`, `seller_deposit` и `D_dispute` обеих сторон | **D3** (`A-03`, `lit_liveness.log`) |
| §2.5, §5.4, §5.6, §9 | Стейк арбитра `S_arb` переведён в USDC пропорционально сумме спора (`β_arb`); штрафы меньшинства (`λ·S_arb`) распределяются между арбитрами большинства | **D4** (`A-05`) |
| §2.5, §3.2–3.3, §5.4, §9 | Кворум `valid_votes ≥ Q_arb > k/2`, подсчёт большинства только по поданным голосам (`v_A > v_B`), невозможна победа при 0 голосов; при ничьей/недокворуме — `e_redraw` до `T_dispute_max` | **D5** (`A-04`, `lit_zero_vote.log`) |
| §4.5, §5.5, §9 | Удалено сжигание USDC при `FOR_B`; остаток `(1 - σ)·seller_deposit` направляется в казну/`keeper_pool` (`remainder_split`); сжигается только `NKG` | **D6** (`A-06`, `lit_burned_usdc.log`) |
| §3.4, §4.2, §4.3 | Награда киперу `R_keeper` возложена на виновную сторону (в рамках её депозита/штрафа); пострадавшая сторона может вызывать таймауты сама | **D7** (`A-07`) |
| §7.3, §9 | Удалены роль `guardian` и `guardian veto`; отмена предложения доступна только автору; добавлена опция таймлока и автоистекающей аварийной паузы `T_pause_max` | **D8** (`G-08`) |
| §2.3, §4.1, §9 | Оформлены два варианта для `amount = 0`: **D9-A** (запрет `amount < A_min`) и **D9-B** (взаимный залог `D_barter_min` обеих сторон и право спора для обеих сторон) | **D9** (`A-10`) |
| §3.3, §4.3 | Штраф `σ` на `seller_deposit` применён также при `LOCKED → EXPIRED` | **D10** (`A-08`) |
| §6.1–6.2, §9 | Двусторонние оценки `(CategoryId, Role)`; байесовское сглаживание `(Σ r_i w_i + m·prior)/(Σ w_i + m)`; взвешивание `w(n, V)` по стоимости сделки; непрерывное затухание `raw_score` с истинным периодом полураспада `ln 2` (устраняет сброс микросделкой) | **D11** (`A-11`, `G-07`, `G-09`) |
| §5.1, §5.6 | Теорема 5.2 переформулирована (фокальное равновесие при условиях, не доминирующая стратегия); Следствие 5.6 заменено явной границей стоимости прямого подкупа от `β_arb` и `V` | Доп. поручение (`02_game_theory.md`) |
| §2.5, §5.2, §5.3, §9 | Добавлен `commit-reveal` (`T_commit`, `T_reveal`), обязательный VRF для панели, включено `alignment_rate ≥ θ_arb` в Def. 5.1 | Доп. поручение (`G-05`, `G-10`, T3 Exp 2) |
| §2.3, §3.3 | Добавлено поле `submit_time` в `Agreement`; добавлены строгие верхние границы времени `t_now < deadline` (`e_start`, `e_submit`) и `t_now < submit_time + T_review` (`e_confirm`, `e_dispute`) | Доп. поручение (`A-09`, `G-01`, `lit_deadline_race.log`) |
| §7.3, §7.4, §9 | Параметры `T_delay`, `T_voting`, `T_timelock`, `N_activity_threshold` и `k` включены в §7.4/§9 как свободные управляемые DAO константы | Доп. поручение (`G-08`) |
| §2.1, §2.4, §5.2, §5.4, §6.2 | Явно оставлены открытыми: возврат `D_reg` (`G-04`), суб-автомат этапов `Milestone` (`G-03`), оффчейн-проверка финсвязей (`G-06`), формула `R_arbitrator`, отзыв при `EXPIRED` | Прозрачность открытых пробелов |
