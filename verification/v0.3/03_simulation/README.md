# W4. Агентные симуляции NoKing v0.3 (`03_simulation`)

## 1. Воспроизведение и окружение

- **Скрипт:** [`sim_noking_v03.py`](sim_noking_v03.py)
- **Окружение:** Python `3.11.2`, `numpy`, `pandas`, `matplotlib` (виртуальное окружение `/tmp/noking_venv`).
- **Воспроизводимость:** `20` независимых прогонов с фиксированными сидами `SEEDS = list(range(100, 120))` (`100..119`); `95%` доверительный интервал рассчитывается как $1.96 \cdot s / \sqrt{20}$.
- **Агрегированная сводка:** [`summary_v03.json`](summary_v03.json).

```bash
cd verification/v0.3/03_simulation
/tmp/noking_venv/bin/python sim_noking_v03.py
```
