# CHANGELOG: NoKing Protocol `v0.2-draft` → `v0.3-draft`

Все изменения в [`protocol/specs/exchange-spec-v0.3.md`](../../protocol/specs/exchange-spec-v0.3.md) внесены строго по утверждённым решениям **E1–E7** и дополнительным предложениям.

| Раздел v0.3 | Что изменено | Основание (Решение / Проблема v0.2) |
|---|---|---|
| §2.5, §3.2, §4.4, §5.2 | **Раунд 2:** при провале панели или кворума остаётся в силе вердикт раунда 1, возвращается только `appeal_deposit`. **Раунд 1:** эскалация (`e_escalate`) в `Category.parent` / `GLOBAL`; при повторном провале `amount` делится 50/50, обе стороны теряют `D_dispute` (`2·D_dispute` распределяются: кипер + 50% честным арбитрам + 50% казне) | **E1** (`N-01`) |
| §2.3, §5.4, §9 | Введён потолок стейка `S_arb_max`, ярусы сделок (`Tier 1/2/3`: `k = 5/7/9`) и явный лимит страхуемой сделки `V_protocol_max` | **E2** (`N-02`) |
| §2.5, §3.2, §5.3 | Разделены штраф меньшинства (`λ = 0.25`) и штраф за `UNREVEALED` (`λ_unrev ∈ (0.25, 1.0]`); `e_redraw` добирает только недостающие места, сохраняя раскрытые голоса | **E3** (`N-03`, `N-05`) |
| §2.3, §4.1, §9 | Запрещён `amount = 0` (`amount ≥ A_min > 0`); вариант D9-B полностью исключён | **E4** (`N-06`) |
| §4.1–4.2, §9 | Проблема оплаты киперов в `REVIEW` (`N-07`) решается через `A_min` без дополнительного залога покупателя | **E5** (`N-07`) |
| §5.2, §6.1–6.4 | Запрещена оценка победителю от проигравшей стороны в `RESOLVED`; добавлена оценка продавца покупателем при `EXPIRED`; добавлен счётчик `unique_counterparties` для допуска арбитров и SBT | **E6** (`N-09`, `G-07`) |
| §2.1, §2.4, §9 | `Milestone` (`G-03`) и вывод `D_reg` (`G-04`) оставлены в разделе `[OPEN, v1.0]`; для свободных параметров и `R_arbitrator` даны `[RECOMMENDED]` диапазоны | **E7** |
| §5.1, §5.5 | Симметризирована премия арбитрам: при `FOR_B` арбитры получают эквивалент `D_dispute` из `seller_deposit` (устраняет pro-seller перекос `p*`) | Доп. предложение (`W3.3`) |
| §3.2, §5.6 | Добавлена компенсация задержки (`30%` от `appeal_deposit`) победителю при неудачной апелляции; добавлен `T_cancel_grace` в `DRAFT` | Доп. предложения (`N-04`, `N-08`) |
| §5.2 | Алгоритм 5.1 переведён на `O(k · log |E|)` Sortition Sum-Tree / Fenwick вместо `O(|E|)` Fisher–Yates | Доп. предложение (газ-DoS) |
