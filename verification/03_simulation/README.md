# T3. Агентная симуляция сети NoKing

## 1. Параметры среды и воспроизведение

- **Скрипт:** [`sim_noking.py`](sim_noking.py)
- **Среда:** Python `3.11.2`, `numpy`, `scipy`, `pandas`, `matplotlib` (установлены в venv).
- **Зёрна ГПСЧ (`SEEDS`):** `100..119` (20 независимых прогонов на каждую точку параметра).
- **Доверительные интервалы:** 95% ДИ ($\mu \pm 1.96 \cdot s / \sqrt{20}$).
- **Масштаб:** в экспериментах 1–2 по 300 споров на прогон (6 000 споров на точку), в эксперименте 3 по 1 000 сделок на прогон (20 000 сделок на точку).

### Инструкция запуска

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install numpy scipy pandas matplotlib
python3 verification/03_simulation/sim_noking.py
```

Выходные данные сохраняются в [`data/`](data/) и [`plots/`](plots/), сводка — в [`summary.json`](summary.json).

## 2. Результаты экспериментов

### Эксперимент 1: Доля злонамеренных / сговорившихся арбитров и порог устойчивости
- **График:** [`fig1_malicious_threshold.png`](plots/fig1_malicious_threshold.png)
- **Данные:** [`exp1_malicious_fraction.csv`](data/exp1_malicious_fraction.csv)
- **Ключевые наблюдения ($N_{\text{pool}} = 60$, точность честного арбитра $95\%$):**
  - **Без апелляции (1-я инстанция):** при $k = 5$ и $f_{\text{mal}} = 20\%$ доля неверных вердиктов составляет **$8.68\% \pm 0.53\%$**; при $f_{\text{mal}} = 30\%$ — **$21.68\% \pm 1.13\%$**; при $f_{\text{mal}} = 40\%$ — **$36.33\% \pm 1.25\%$**; при $f_{\text{mal}} = 50\%$ — **$55.15\% \pm 1.13\%$**.
  - **С апелляцией ($k' = 17$, требуется $|E| \ge 51$):** при $f_{\text{mal}} \le 20\%$ ошибки подавляются до **$0.02\% \pm 0.03\%$**, при $30\%$ — до **$1.10\% \pm 0.23\%$**, при $40\%$ — до **$8.80\% \pm 0.63\%$**. При $f_{\text{mal}} \ge 45\%$–$50\%$ система деградирует стремительно ($17.95\% \to 32.03\%$).
  - **Ловушка `OVERSAMPLE_FACTOR = 3` для $k = 7$:** при $N_{\text{pool}} = 60$ и $k = 7$ размер апелляции равен $k' = 23$, что требует $3 \times 23 = 69 > 60$ арбитров. Из-за жёсткого требования Алгоритма 5.1 апелляция **блокируется**, поэтому при $f_{\text{mal}} = 30\%$ схема с $k = 7$ выдаёт **$16.85\% \pm 0.79\%$** неверных вердиктов — в **15 раз хуже**, чем $k = 5$ с работающей апелляцией ($1.10\%$).
- **Статус:** `SUPPORTED` (устойчивость до ~$30\%$ сговорившихся арбитров зависит от доступности апелляции и достаточности пула $|E| \ge 3k'$).

### Эксперимент 2: Схемы отбора арбитров и отсутствие commit-reveal (стадный эффект)
- **График:** [`fig2_selection_commit_reveal.png`](plots/fig2_selection_commit_reveal.png)
- **Данные:** [`exp2_selection_and_herding.csv`](data/exp2_selection_and_herding.csv)
- **Ключевые наблюдения ($N_{\text{honest}} = 40$, $k = 5$, добавлено $M_{\text{sybil}} = 20$ Сивилл, доля $33.3\%$):**
  - `Uniform + Commit-Reveal`: **$25.28\% \pm 1.21\%$** ошибок.
  - `Uniform + Open Voting (Herding 60%)` *(буквальная спека без commit-reveal)*: **$39.27\% \pm 1.46\%$** ошибок (**+14 п.п. роста брака** из-за копирования ранних голосов!). Даже без Сивилл ($M = 0$) открытое голосование поднимает ошибки с $0.13\%$ до $2.78\%$.
  - `Reputation-Weighted` (вес 5:1): снижает ошибки при $M=20$ до **$2.13\% \pm 0.35\%$**.
  - `Stake-Weighted` (вес 10:1): снижает ошибки при $M=20$ до **$0.72\% \pm 0.25\%$** *(но уязвимо для богатого атакующего-одиночки)*.
- **Статус:** `SUPPORTED` (равномерная выборка `Algorithm 5.1` без учёта репутации/стейка и без commit-reveal резко деградирует под Сивиллами).

### Эксперимент 3: Массовые ложные споры, баг воздержания (Def. 5.2) и неплатёжеспособность `keeper_pool`
- **График:** [`fig3_mass_disputes_keeper.png`](plots/fig3_mass_disputes_keeper.png)
- **Данные:** [`exp3_mass_disputes_and_keeper.csv`](data/exp3_mass_disputes_and_keeper.csv)
- **Ключевые наблюдения (логнормальные сделки с медианой $80\text{ USDC}$, $20\%$ злонамеренных арбитров и $25\%$ вероятностью `ABSTAIN`):**
  - Около **$21.7\%$–$24.9\%$** всех ложных споров нечестный покупатель выигрывает исключительно из-за ошибки Def. 5.2 (`ABSTAIN` засчитывается в пользу `FOR_B` при отсутствии большинства у `FOR_A`), получая положительное матожидание **+$29.3$..+$36.4 USDC** на ложный спор.
  - Пул киперов (`0.1%` от закрытого объёма против фиксированной выплаты $R_{\text{keeper}} = 0.50\text{ USDC}$) уходит в **хронический дефицит ~$31.5 \pm 4.8\text{ USDC}$ на каждые 1 000 сделок** при $2\%$ споров ($10\%$ просрочек, $20\%$ автоподтверждений).
- **Статус:** `SUPPORTED` (количественно подтверждены уязвимости A-04 и A-07).
